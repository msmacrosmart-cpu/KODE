# Nova TV (skin.novatv)

Skin Kodi 21 (Omega, xbmc.gui 5.17.0), 1920x1080, preto fosco / branco / cinza.

Instalar: Complementos > Instalar de arquivo zip > skin.novatv.zip > Interface > Skin.

- `xml/` janelas, `xml/Includes.xml` blocos reutilizáveis, `colors/defaults.xml` paleta, `xml/Font.xml` fontes (Liberation Sans, SIL OFL).
- Banner hero: lista 9100 (lançamentos recentes). Menu: lista 9000. Widgets: grouplist 9500.
- Veja `docs/JANELAS.md`.

Não testado em um Kodi real: confira o kodi.log após instalar.
